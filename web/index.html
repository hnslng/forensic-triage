BEGRIFFE ERKLÄREN
ANDROID-APP-ID / PACKAGE-ID
Eindeutige technische Kennung einer Android-App. Beispiel: io.metamask. Zu finden z. B. im offiziellen Google-Play-Eintrag, häufig in der URL hinter id=. Nicht raten.
IOS BUNDLE-ID
Eindeutige technische Kennung einer iPhone-/iPad-App. Beispiel: com.hersteller.app. Nur aus überprüfbarer Quelle übernehmen.
ALIAS
Alternativer oder früherer Name derselben App. Beispiel: Xumm als früherer Name von Xaman. Quelle: Herstellerseite, Store oder dokumentierte Umbenennung.
SUCHBEGRIFF
Zusätzlicher Begriff für eine vorsichtige Erkennung, falls keine eindeutige App-ID greift. Beispiel: metamask. Unscharfe Suchbegriffe können Fehlalarme erzeugen.
ID FEHLT
Für diese Plattform ist noch keine verifizierte technische App-ID gespeichert. Die App kann gegebenenfalls nur über ihren Namen oder Alias erkannt werden.
PLATTFORM-ID-STATUS
✓ = ID verifiziert; ? = noch keine verifizierte ID hinterlegt; — = nachweislich nicht anwendbar. Eine fehlende ID bedeutet nicht, dass keine App für die Plattform existiert.
LEGACY
Ältere, umbenannte oder eingestellte App, die auf vorhandenen älteren Geräten noch installiert sein kann.
VERIFIZIERT
Die technische Kennung wurde anhand einer nachvollziehbaren Quelle geprüft.
RELEVANZ
HOCH = starker Krypto-Hinweis (Wallet/Börse); MITTEL = Portfolio/Steuer/Zahlung; NIEDRIG = vage Hinweise; NEUTRAL = Banking/Messenger/Cloud erzeugt keinen Krypto-Hinweis.
AKTIV
